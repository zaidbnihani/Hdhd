# ZTube - تطبيق مشاهدة الفيديو المحسّن لـ Android TV

## 🎬 نظرة عامة

**ZTube** هو تطبيق فيديو متقدم مصمم خصيصاً لأجهزة **Android TV**. يوفر تجربة مشاهدة سلسة وممتعة مع واجهة مستخدم حديثة وميزات قوية.

---

## ✨ الميزات الرئيسية

### 🎥 تشغيل الفيديو
- دعم كامل لفيديوهات الويب بجودات متعددة (144p - 4K)
- تشغيل في الخلفية (الصوت فقط أو صورة داخل صورة)
- التحكم في السرعة والترجمات الحية
- معالجة أخطاء الشبكة التلقائية
- استئناف التشغيل من حيث توقفت

### 📺 الواجهة الحديثة
- **تصميم أحمر جريء** بلون #F15B5B مع أيقونة Z مميزة
- واجهة مستخدم محسّنة لشاشات التلفاز (10-foot UI)
- عرض الشبكة والقوائم الذكية
- دعم كامل للتنقل عبر جهاز التحكم الذكي
- **قسم مخصص لـ Shorts** سهل الوصول

### 📱 Shorts
- قسم منفصل لفيديوهات Shorts
- زر سريع لعرض الـ Shorts
- خيارات لإخفاء أو عرض Shorts
- تشغيل سريع وسهل

### 🔔 الإشعارات والسجل
- تسجيل تاريخ المشاهدة
- نظام الإشعارات الذكي
- استئناف التشغيل من حيث توقفت
- قائمة المشاهدة لاحقاً

### ⚙️ الإعدادات المتقدمة
- خيارات جودة الفيديو والصوت القابلة للتخصيص
- إعدادات الترجمات المتقدمة
- التخزين المؤقت القابل لل��خصيص
- خوارزميات تصحيح الأخطاء الذكية
- اختيار أو إخفاء الفئات المختلفة

### 🌍 دعم كامل للعربية
- جميع النصوص والواجهات بالعربية 100%
- توجيه من اليمين إلى اليسار (RTL)
- دعم الترجمات العربية
- أسماء الأزرار والقوائم بالعربية

## 🎨 الألوان والتصميم

### اللوحة اللونية الأساسية

| العنصر | اللون | الكود |  الاستخدام |
|------|------|------|----------|
| أحمر أساسي | 🔴 | `#F15B5B` | الخلفيات، الأزرار، الأيقونات الرئيسية |
| أبيض | ⚪ | `#FFFFFF` | النصوص، الأيقونات، التفاصيل |
| رمادي داكن | ⚫ | `#343434` | الخلفيات الثانوية، الفواصل |
| أحمر داكن | 🔻 | `#D94B4B` | الحالات المركزة، التأثيرات |

### الأيقونة

تم تصميم أيقونة التطبيق باستخدام:
- **الحرف Z** باللون الأبيض
- **رمز التشغيل** (مثلث أبيض) داخل الحرف
- **خلفية حمراء** بزوايا مدورة
- **تصميم حديث** يعكس جودة الفيديو

```
┌──────────────────┐
│  ╔════════════╗  │
│  ║   Z    ▶   ║  │
│  ╚════════════╝  │
└──────────────────┘
   (أحمر #F15B5B)
```

## 📋 المتطلبات

### النظام
- **Android**: 5.0 (API 21) فما فوق
- **RAM**: 2GB على الأقل (موصى به 4GB)
- **التخزين**: 100MB
- **اتصال إنترنت**: مطلوب للتشغيل

### الأجهزة المدعومة
- Android TV (جميع الإصدارات المدعومة)
- أجهزة البث (Streaming Devices)
- أجهزة التلفاز الذكية بنظام Android

## 🚀 البدء السريع

### البناء
```bash
# استنساخ المستودع
git clone https://github.com/zaidbnihani/Hdhd.git
cd Hdhd

# بناء المشروع
./gradlew build
```

### التثبيت
```bash
# تثبيت النسخة Debug
./gradlew installDebug

# تشغيل التطبيق
adb shell am start -n com.liskovsoft.smartyoutubetv2.tv/com.liskovsoft.smartyoutubetv2.tv.ui.main.SplashActivity
```

## 📝 الملفات المعدلة

### التحديثات الرئيسية:

1. **strings.xml** - تغيير اسم التطبيق إلى ZTube مع جميع النصوص بالعربية
2. **colors.xml** - تحديث الألوان إلى المخطط الأحمر الجديد
3. **AndroidManifest.xml** - تعديل أيقونة التطبيق
4. **ztube_icon.xml** - أيقونة جديدة بتصميم Z مع رمز التشغيل
5. **icon_shorts.xml** - أيقونة Shorts جديدة
6. **shorts_button.xml** - زر Shorts جديد في الواجهة
7. **dimens.xml** - أبعاد محسّنة للواجهة
8. **values-ar/strings.xml** - جميع النصوص بالعربية
